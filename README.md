# Describe the House — Vocabulary Quizzes

An offline-ready vocabulary game for English learners (A1–A2).

- 74 words in 4 sets: furniture & rooms, house adjectives, materials, prepositions of place.
- Every word has a built-in recording (no external audio) and a hand-drawn illustration.
- Four question types: picture → word, listen → picture, spelling, memory challenge.
- Standard and Challenge modes, 10-question or full-set rounds.
- Works on phones, tablets and computers. No account, no installation.

Open `index.html` locally, or publish the folder with GitHub Pages.

Made for classroom use.
